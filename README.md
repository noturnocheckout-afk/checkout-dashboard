# Checkout Dashboard

Dashboard de Gestão Operacional do Checkout Noturno.

## Objetivo

Centralizar os indicadores operacionais do Checkout em um único painel, permitindo acompanhar em tempo real:

- Pedidos processados
- Peças processadas
- Pedidos por hora
- Peças por hora
- Horas operadas
- Produtividade por colaborador
- Qualidade
- Metas
- Evolução diária, semanal e mensal
